## The letter

> **P**

The entry is one letter: the letter of the word that describes the day. Behind P sits "procrastinating" — the day spent putting everything off until tomorrow. It is vivid because it names a specific activity everyone has done, funny because it is a confession told on itself, and true because the day really was spent that way. No word, no gloss, no punctuation — the letter is the whole entry.

## Why this letter

P was picked by judging candidate letters pairwise against the field's most-entered letters, using the bounty judge's own five criteria in order. "Procrastinating" beats the vague mood words (tired, stressed, amazing) because it calls up a sharp picture instead of a mood, and it beats the plain exhaustion words because the confession lands at once and a reader repeats it to a friend. P is also the letter's exact initial, not a stretch, and it is not one of the brief's own examples. The program writes exactly one character, no newline, to `/output/entry.txt`.

```sh
python3 main.py
```
